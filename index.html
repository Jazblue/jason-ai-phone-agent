Project Overview

The Jason AI Phone Agent is an AI phone agent and AI-powered voice assistant designed to handle inbound and outbound calls with natural, conversational AI. Built using Vapi for voice orchestration and Twilio integration for telephony, the project demonstrates real telephone calling with a UK number. AWS backend services (Lambda, API Gateway and DynamoDB) are planned for future call logging, automation and scaling.

The primary goal is to explore how modern AI voice platforms can be integrated with traditional telephony and cloud services to create scalable, intelligent phone support that can qualify leads, schedule appointments, answer FAQs, and escalate to human agents when needed.
