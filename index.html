Project Overview

The Jason AI Phone Agent is an AI-powered voice support system designed to handle inbound and outbound phone calls with natural, conversational AI. Built using Vapi for AI voice orchestration and Twilio for telephony infrastructure, this project demonstrates real telephone calling functionality with a UK number ([UK number]). AWS backend services (Lambda, API Gateway, DynamoDB) are planned for future integration to enable call logging, automation, and scaling.

The primary goal is to explore how modern AI voice platforms can be integrated with traditional telephony and cloud services to create scalable, intelligent phone support that can qualify leads, schedule appointments, answer FAQs, and escalate to human agents when needed.

Security Considerations

  • Never commit Twilio Auth Tokens or API keys to GitHub
  • Never expose AWS access keys or secrets in client-side code
  • Use environment variables and secrets management (GitHub Secrets, AWS Secrets Manager)
  • Keep production credentials outside the public repository
  • Validate and sanitize all webhook inputs
  • Implement rate limiting and authentication for webhooks
  • Follow principle of least privilege for IAM roles
